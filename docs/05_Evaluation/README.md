# Level 5 — Evaluation Documentation

This level is for documenting the evaluation work done by each group member.

The project is a group project. Different members built different workflows for different layers. The OpenClaw/NetClaw bridge is only one implementation path used for part of the Systems Layer work. Other workflows may use n8n AI Agent nodes with Ollama as the AI layer.

## Evaluation layers

| Layer | Folder | Purpose |
| --- | --- | --- |
| Network Layer | `Network_Layer/` | Network operation, policy validation, and network-user interaction evaluations. |
| Systems Layer | `Systems_Layer/` | Infrastructure, VM, system administration, monitoring, and automation evaluations. |

## Documentation rule

Each team member should document their own workflows, test cases, screenshots, results, and scripts inside the correct subsection folder.

Do not place secrets, API keys, bot tokens, SSH private keys, or licensed images in this repository.
