# Admin Network Operations Bot

This folder contains the evaluation documentation for the **Admin Network Operations Bot 1** workflow.

## Folder structure

- `N8N Workflow Documentation/`
  - documentation for what was built in n8n under **Admin Network Operations Bot 1**
  - includes a `Workflow JSON/` subfolder containing the main workflow export and child workflow exports
- `GNS3 Network Documentation/`
  - documentation for the GNS3 lab, network setup, and devices used with this workflow
- `Script Code/`
  - extracted scripts and code used by the workflow
- `TEST_CASES_AND_EVIDENCE.md`
  - evaluation checklist, test cases, and evidence tracker

## Notes

This structure follows your requested separation:

- **n8n documentation** stays outside the script folder;
- **GNS3 documentation** stays outside the script folder;
- **Script Code** only stores script/code artifacts used by the workflow.
