# n8n Workflows

Place exported n8n workflow JSON files for the Systems Infrastructure and Administration evaluation here.

Currently included:

- `openclaw-proxmox-orchestrator.workflow.json` — the systems infrastructure workflow for Proxmox/VM status, VM control, IP lookup, diagnostics, snapshots, and safe administrative operations.

If additional n8n workflows are used for this section, export them from n8n and add them to this folder.

Do not include credentials, API keys, tokens, or private keys in exported workflow files.
